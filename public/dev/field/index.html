02 / Owner economics

Recovered economics, not battery cells

Every recommendation starts with the owner’s revenue stack and site constraints. Augmentation moves forward only when the downside case clears the hurdle.

Value sources
Recover contracted capability or capacity value. Extend discharge duration where market rules and dispatch value support it.
Cost + risk
Installed equipment, outage time, integration, warranties, degradation, operating changes, and financing.
Go / no-go
A documented decision with key sensitivities, risks, and an implementation path.
