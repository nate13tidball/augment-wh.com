Connect Vercel Analytics
  1. Enable Web Analytics in your Vercel project and add its tracking script to the pages you want to measure. Collection starts after deployment.
  2. In Vercel → Project → Settings → Environment Variables, set ANALYTICS_VERCEL_TOKEN to an access token authorized for this project, and ANALYTICS_PROJECT_ID to its project ID.
  3. For a team-owned project, also set ANALYTICS_TEAM_ID. Omit it for a personal project.
  4. Keep the API token server-side and redeploy. This page loads automatically. No historical visits are collected retroactively.
